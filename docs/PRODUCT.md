# 스타일로그 2.2 — 지금 서비스가 하는 일

하루 코디를 남기고, 날씨와 상황으로 다시 찾는 기록 앱이다. 버전 표기는 `scripts/config.js`의 `APP_VERSION`.

전략·Phase·다음 버전·Notion 티켓 연결은 [ROADMAP.md](ROADMAP.md)에 정리되어 있다.

## 사용자가 하는 일

1. 사진을 3:4로 맞추고, 그날 날씨·체감·상황·착장 품목·메모를 남긴다.
2. 홈에서 사진과 날짜·날씨·상황이 한 카드인 목록을 훑고, 필터로 좁힌 뒤 상세를 연다.
3. 상세에서 홈으로 돌아오면 보던 위치와 필터가 그대로다. 홈에서 상세로 들어가면 상세는 맨 위다.
4. 옷장에 옷을 모아 두고, 작성할 때 구분과 옷을 골라 넣는다. 옷장 시트는 손잡이를 내려 닫을 수 있다. 이름은 작성 화면과 옷장에서 바꿀 수 있고, 지난 기록에도 반영된다.
5. 만족한 코디는 즐겨찾기로 모은다. 별도의 만족도 점수는 없다.

## 상황

화면에서 고르는 값은 다섯 개다.

| 화면 | 저장 코드 |
|------|-----------|
| 회사 | `work` |
| 일상/데이트 | `daily` |
| 여행 | `travel` |
| 운동 | `workout` |
| 경조사 | `guest` |

예전 기록의 `interview`는 회사, `date`와 `plan`은 일상/데이트로 묶여 보인다. 컬럼은 `style_logs.tpo`. Alpha와 리얼 DB에서 `docs/supabase/style_logs_add_tpo.sql`을 실행해야 저장된다.

## 이번 버전에 없는 것

- 조합 분석, 추천, 자유 태그 검색, 관리자 집계
- 만족도 컬럼을 제품에서 다시 쓰지 않는다. 예전에 만들어 둔 컬럼이 있어도 화면은 즐겨찾기만 쓴다.
